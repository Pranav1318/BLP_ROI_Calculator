# Isarwerk AP automation: what is it worth?

Interactive value calculator for a fictional German manufacturer (Isarwerk Präzision GmbH).
Change assumptions in the sidebar and see year-1 net value, payback, confidence levels and a stress test.

Live app: https://isarwerkgmbh-n7ag6cgkd5nkzsmzaxnorq.streamlit.app/

## Run locally
```
pip install -r requirements.txt
streamlit run app.py
```

## Files
- `app.py`: the full app (model + interface)
- `requirements.txt`: Python dependencies for Streamlit Community Cloud

Illustrative case, all company data is fictional. Not a BLP quotation.
